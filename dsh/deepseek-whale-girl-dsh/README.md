# 鲸鱼娘伙伴（DeepSeek Harness 插件）

把 Codex 宠物包 `whale-girl` 的鲸鱼娘搬进 DeepSeek Harness Web 界面。她现在有三个落点：输入框下方一条小桌宠、页面右下角一只可拖动、始终挂在界面最上层的宠物，以及空白首页上的站立形象。

素材来自 `鲸鱼娘/whale-girl` 宠物包（v2 图集，192×208 单元格，8 列 × 11 行）。插件只读取图集副本，不改动原包。

## 三个落点

1. **挂在界面外的浮游宠物**（`shell.overlay`，默认在右下角）：默认 96px 高，覆盖在整个界面之上，不在任何栏目的滚动区里。**可以按住拖动**，松手后位置会记住；**滚轮调大小**（48–240px，聚焦后也可用 ↑/↓ 键），**双击恢复 96px**。位置和大小都存在浏览器 localStorage 的 `whale-girl.float-anchor`（`{x, y, size}`）。点她或按 Enter / 空格会跳一下。
2. **输入框下方**（`conversation.composer.dock`，44px 高）：跟在活动统计、用量统计后面的小桌宠。
3. **空白首页**（`conversation.hero.frame`，复用官方 `pixel-whale` 图层）：180px 高，站在首页左下角。视口窄于 1200px 或矮于 780px 时隐藏，避免压到居中的输入卡片。

浮游宠物跟着"任意一个会话"的状态变化：有会话在跑就工作，有会话等你回答或批准就等待。底部那只只跟随当前会话。首页那只只在待机与挥手之间切换。

## 状态与动画

| 状态 | 动画 |
| --- | --- |
| 打开或切换会话 | 挥手一次 |
| 没有任务 | 待机 idle |
| 正在执行 | 工作中 running |
| 等待回答或批准 | 等你回复 waiting |
| 一轮刚结束（运行 → 停止） | 查看结果 review，约 1 秒后回到待机 |
| 点击 / 键盘触发 | 跳一下 jumping |

每帧时长取自宠物包的 `animations.json`，已内联进插件。系统开启"减少动态效果"时停在首帧；运行中切换该系统设置也会立即生效。

## 安装

1. 把本文件夹放到一个**不会再移动**的位置。
2. 打开 **插件（Plugins）→ 添加插件（Add plugin）**，在输入框里填入本文件夹的绝对路径（本地目录安装）。

装好后刷新页面或新开一个会话即可看到。之后更新 `client.js` 等文件，刷新页面生效；若浏览器仍用旧图，停用再启用该插件。

> 这是本地链接安装：移动或删除这个目录会让插件失效。同一台机器上不要同时安装新旧两份同名包。

## 说明与限制

- 图集 2.5 MB，文件名带内容 revision，经 `/plugins/<包名>/assets/` 路由按需加载。
- 浮游宠物会跟着界面走，包括插件、设置等页面；它只在自身的范围内接管鼠标，页面其余部分照常可点。鼠标停在她身上滚动滚轮时是调大小，不会滚动页面。
- 没有可靠的"失败"信号，因此 `failed`、`running-left/right`、`look-a/b` 这些图集行暂不播放。
- 首页图层复用了官方图层 id，属于替换官方装饰；官方若改动图层 id 或布局，这里需要跟着调整。
- 颜色沿用宿主主题变量；角色本身使用素材自带配色。
- 素材版权：来自你提供的 `whale-girl` 宠物包，非 DeepSeek 官方素材。
